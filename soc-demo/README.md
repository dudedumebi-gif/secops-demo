# SOC Demo

Open `index.html` in a browser. No build step, no server.

A lightweight, Splunk-style interactive SOC console, de-branded and with all data labelled simulated.

Views: Mission Control, Incident Queue (10 incidents), investigation drawer, Search & Hunt (4 SPL hunts, convert-to-detection), Detection Lifecycle board, SOAR playbooks (9, with human approval gate for high-impact actions), MITRE ATT&CK coverage heat map, Telemetry & Log Onboarding, Metrics & KPIs + Roadmap & Backlog with a scored intake form.

Suggested walkthrough: Mission Control → critical ransomware incident → run its SOAR playbook and approve the high-impact action → Search & Hunt → Detection Lifecycle → Telemetry Onboarding → Roadmap & Backlog.
